# Entry points a stage run needs that the static descent cannot follow.
#
# The stage's module code is not the boot chain's: at the f11400 capture bank $6B
# differs from the disc's bank $6B in 7,642 of 8,192 bytes.  So a stage build is
# translated from the *state's own bank images* (build.sh stage <img>), and its
# entry points are the ones the running machine is observed to use.
#
# Format: BANK:ADDR  (the bank is authoritative; the page comes from the address,
# so the unit is emitted where the machine's PC actually is).  Fill this file with
#   python3 tools/discover_seeds.py --state <state.img>
# which runs the stage host, reads its UNTRANSLATED report and adds what it finds.
